# S3 Client Utility

A boto3-based S3 client wrapper that supports standard AWS S3 and S3-compatible services (e.g. MinIO, RustFS). It handles credential resolution via environment variables, automatic multipart copying for large objects, and metadata/tag preservation.

---

## Installation

Install the S3 helper dependencies with the `s3` extra:

```bash
python -m pip install "pygarden[s3]"
```

If you are working from a local checkout with `uv`, use either:

```bash
uv pip install -e ".[s3]"
```

or:

```bash
uv sync --extra s3
```

The `s3` extra installs the libraries used by `pygarden.s3`, primarily
`boto3` and `humanize`.

## Environment Variables

Credentials and connection settings are resolved in the following **priority order**:

1. Explicit constructor argument
2. Prefixed env var (e.g. `MYSTORE_ENDPOINT`) — only if `env_prefix` is provided
3. Default `S3_*` env var

| Variable | Alias | Description |
|---|---|---|
| `S3_ENDPOINT` | `MINIO_ENDPOINT` | URL of the S3-compatible service |
| `S3_ACCESS_KEY` | `MINIO_ACCESS_KEY` | Access key credential |
| `S3_SECRET_KEY` | `MINIO_SECRET_KEY` | Secret key credential |
| `S3_USE_SSL` | `MINIO_USE_SSL` | Whether to use SSL (`true` / `false`) |
| `S3_REGION` | — | AWS region name |

> **Note:** `S3_USE_SSL` is ignored by boto3 when the endpoint URL already contains an `http://` or `https://` scheme.

### Minimal Setup (AWS S3)

```bash
export S3_ACCESS_KEY="AKIAIOSFODNN7EXAMPLE"
export S3_SECRET_KEY="wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY"
export S3_REGION="us-east-1"
```

### MinIO / Self-hosted Setup

```bash
export S3_ENDPOINT="https://minio.example.com"
export S3_ACCESS_KEY="minioadmin"
export S3_SECRET_KEY="minioadmin"
export S3_USE_SSL="true"
```

### Using a Prefix (multiple S3 connections)

When `env_prefix` is provided, the client first looks for `{PREFIX}_*` variables before falling back to the `S3_*` defaults. This allows you to configure multiple S3 connections in the same environment:

```bash
export STORE_A_ENDPOINT="https://s3.amazonaws.com"
export STORE_A_ACCESS_KEY="AKIA..."
export STORE_A_SECRET_KEY="abc123..."

export STORE_B_ENDPOINT="https://minio.internal"
export STORE_B_ACCESS_KEY="minioadmin"
export STORE_B_SECRET_KEY="minioadmin"
```

```python
store_a = S3(env_prefix="STORE_A")
store_b = S3(env_prefix="STORE_B")
```

## Initialization

```python
from pygarden.s3 import S3

# From environment variables
s3 = S3()

# Explicit credentials
s3 = S3(
    endpoint="https://minio.example.com",
    access_key="mykey",
    secret_key="mysecret",
    use_ssl=True,
    region="us-east-1",
)

# With an env prefix
s3 = S3(env_prefix="STORE_A")
```

## Direct boto3 Access

The underlying boto3 client is exposed via the `S3.client` attribute, giving you full access to any boto3 S3 operation not covered by the wrapper methods:
See the [AWS Docs](https://docs.aws.amazon.com/boto3/latest/reference/services/s3.html) for more details on available client functions. 

It's recommended to use `upload_file` over `put_object`, as `upload_file` will handle large files more elegantly. 

```python
s3 = S3()

# List all buckets
response = s3.client.list_buckets()
for bucket in response["Buckets"]:
    print(bucket["Name"])

# Upload a file
s3.client.upload_file("local_file.csv", "my-bucket", "data/file.csv")

# Download a file
s3.client.download_file("my-bucket", "data/file.csv", "local_copy.csv")

# Generate a presigned URL
url = s3.client.generate_presigned_url(
    "get_object",
    Params={"Bucket": "my-bucket", "Key": "data/file.csv"},
    ExpiresIn=3600,
)

# Put an object directly
s3.client.put_object(
    Bucket="my-bucket",
    Key="data/hello.txt",
    Body=b"Hello, world!",
)
```

## Methods

### `confirm_client()`

Verifies the client can connect by listing buckets. Returns `True` on success, `False` on failure.

```python
if not s3.confirm_client():
    raise RuntimeError("Could not connect to S3")
```

---

### `object_exists(bucket_name, object_name, *, check_dir=False)`

Checks whether an object key exists in a bucket. Optionally falls back to checking for a virtual directory prefix.

```python
if s3.object_exists("my-bucket", "data/report.csv"):
    print("Object found")

# Also check if it's a directory prefix
if s3.object_exists("my-bucket", "data/reports", check_dir=True):
    print("Found as object or directory")
```

---

### `directory_exists(bucket_name, prefix)`

Checks whether a virtual directory (key prefix) exists by listing up to one object beneath it.

```python
if s3.directory_exists("my-bucket", "data/2024"):
    print("Directory exists")
```

---

### `copy_with_tags(*, src_bucket, src_key, dst_bucket, dst_key)`

Copies an object to a new location, preserving all metadata and tags. Automatically switches to multipart copy for objects ≥ 5 GiB.

```python
s3.copy_with_tags(
    src_bucket="source-bucket",
    src_key="data/original.parquet",
    dst_bucket="dest-bucket",
    dst_key="archive/original.parquet",
)
```

---

### `move_object(src_bucket, src_key, dst_bucket, dst_key)`

Moves an object by copying it (with tag/metadata preservation) and then deleting the source. The source is only deleted after a successful, validated copy.

```python
s3.move_object(
    src_bucket="landing-bucket",
    src_key="inbox/data.csv",
    dst_bucket="processed-bucket",
    dst_key="done/data.csv",
)
```

---

### `get_matching_objects(bucket, prefix=None, pattern=None)`

Lists all objects under a prefix whose filenames match a glob pattern. Returns a list of `S3Object` dicts with keys: `Key`, `LastModified`, `ETag`, `Size`, `StorageClass`.

```python
# All objects in a prefix
objects = s3.get_matching_objects(bucket="my-bucket", prefix="data/2024/")

# Filter by glob pattern
csv_files = s3.get_matching_objects(
    bucket="my-bucket",
    prefix="data/2024/",
    pattern="*.csv",
)

for obj in csv_files:
    print(obj["Key"], obj["Size"])
```

## Multipart Copy Configuration

For large object copies, the client automatically uses multipart upload. The thresholds can be tuned at initialization:

```python
s3 = S3(
    multipart_threshold=2 * 1024**3,   # Switch to multipart above 2 GiB (default: 5 GiB)
    multipart_part_size=128 * 1024**2, # 128 MiB per part (default: 256 MiB, min: 5 MiB)
)
```

| Parameter | Default | Minimum | Maximum |
|---|---|---|---|
| `multipart_threshold` | 5 GiB | — | 5 GiB (AWS hard limit) |
| `multipart_part_size` | 256 MiB | 5 MiB | — |

If either value is out of bounds, a warning is logged and the value is clamped automatically.
